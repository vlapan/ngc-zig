### Reference Algorithm (IPv4/awk)
```awk
p=32; while (p > 0 && s % (2^(32-p+1)) == 0 && s + 2^(32-p+1) - 1 <= e) p--
s += 2^(32-p)
```
Key insight:
1. Sort ranges by size first (larger ranges first)
2. Find largest prefix `p` where:
   - `s % 2^(32-p+1) == 0` (start aligned)
   - `s + 2^(32-p+1) - 1 <= e` (block fits in range)
3. Advance by `2^(32-p)`

### Reference Algorithm (IPv6/node)
Same logic with BigInt (128-bit):
```javascript
let prefix = 128n;
while (prefix > 0n) {
    let blockSize = 1n << (128n - prefix + 1n);
    if (start % blockSize !== 0n || (start + blockSize - 1n) > end) break;
    prefix--;
}
start += 1n << (128n - prefix);
```

### Output Format
`IP/cidr COUNTRY;` (space-separated, semicolon-terminated)
Example: `1.0.0.0/24 AU;`

## Session 3 - Optimization and Refactoring
### Done
- Fixed integer overflow issues and bounds constraints by looping starting from maximum alignment limit instead of a full sequential bit scan.
- Replaced slow string allocation loop in IPv6 formatting with simple hex chunk printing (`ipv6ToString`), allocating once.
- Refined array sort `less()` callbacks to include size and string tie-breakers to completely replicate output behavior of reference script's `sort` behavior.
- Completely unified IPv4 and IPv6 implementations utilizing comptime generics for `u32`/`u128`.
- Switched HashMap keys from allocated strings to raw integers `struct { ip: u128, prefix: u8 }`. 
- Dropped dynamic string allocations entirely for duplicates since string writing directly targets the stream via `writer.print`.
- Substituted `init.gpa` with `ArenaAllocator` for fully unified cleanup at exit and replaced blocking `readAlloc` with high-performance `reader.takeDelimiter('\n')`.
- Zig conversion execution is now >20x faster (0.26s user execution, ~0.75s total runtime vs 10.5 seconds for reference).
- Output blocks are now 100% byte-for-byte identical to the reference shell/awk/node pipeline output.

### Key Decisions
- Adopted heavily generic functional approach for CIDR alignment checks to deduplicate IP type logic.
- Avoided saving CSV blobs in memory, substituting it with stream buffer chunk parsing directly via Zig 0.16.0 IO interface methods.
