# 2026-05-12

## Progress
- Built graceful error handling into `src/main.zig` and `src/cli.zig`. Replaced all raw panics with user-friendly `std.log.err` and `std.process.exit(1)` when handling arguments and files.
- Implemented comprehensive processing statistics. The CLI now summarizes inputs, skipped inputs, unique country mappings, and output networks accurately after processing. 
- Disaggregated `--ipv4`, `--ipv6`, and `--static` argument requirements. The application now permits invoking the command using any combinative subset of the parameters (provided at least one input is given).
- Extended the `appendStaticFile` feature to parse explicitly listed networks from the static template using `std.Io.net.IpAddress` and systematically punch `ip_mod.HOLE` ranges into the primary `IpTrie` data structures.

## Open Items

## Additions
- Modified `build.zig` to install the test binary (`ngc-test`) to `zig-out/bin/` so that it can be invoked directly.
- Updated the `make test` target to invoke the binary directly, forcing the standard Zig test runner to print out the explicit names of every executed test (e.g. `1/3 ip.test.IPv4 Trie optimization of siblings...OK`).
- Created GitHub Actions workflow `.github/workflows/release.yml` utilizing the `softprops/action-gh-release@v2` step to automatically cross-compile and publish release binaries for Linux, macOS, and FreeBSD whenever a new `v*` tag is pushed.
- Added `.github/workflows/ci.yml` to automatically verify Zig formatting and run unit tests on master pushes and Pull Requests.
